God pictures shown faintly behind the lyrics
============================================

Put one picture per category in this folder, named exactly:

  vinayaka.jpg       - Vinayaka Songs
  subramanya.jpg     - Subramanyam Swamy Songs
  venkateswara.jpg   - Venkateswara Swamy Songs
  shiva.jpg          - Sivudu Songs
  amma.jpg           - Amma vaari Songs
  ayyappa.jpg        - Ayyappa Songs

.jpeg, .png and .webp also work. If a picture is missing, the site shows a
simple built-in emblem for that deity instead.

Tips
- Portrait (tall) pictures look best on phones.
- Keep each picture under about 300 KB so the site loads quickly on phones
  (resize to roughly 800 px tall).
- Use pictures you have the right to use, e.g. your own photos of the pooja
  room or temple, or images whose licence allows reuse.
- The name before ".jpg" comes from the "bg" value of each category in
  songs.js; add a new category with its own "bg" name to use a new picture.
